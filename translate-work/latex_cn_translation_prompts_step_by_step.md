# 英文 LaTeX 论文翻译为中文 LaTeX/PDF 的分步骤 AI 提示词

本文档用于指导你使用 AI 将任意英文 LaTeX 论文翻译为中文 LaTeX 项目，并最终编译生成 PDF。

核心原则：

1. 不要直接修改英文原文目录，必须复制到中文输出目录后再修改。
2. 不要使用固定专业术语表。必须先根据当前论文动态识别领域，并生成当前论文专属术语表。
3. 翻译时保留 LaTeX 结构、引用、标签、公式、代码、图片路径、变量名、函数名、URL、地址和哈希值。
4. 使用正式、通顺、忠实原文的中文学术论文表达。
5. 最终使用 XeLaTeX 或 latexmk 编译生成中文 PDF。

使用方式：

- 如果 AI 能访问本地文件，例如 Codex、Cursor、VS Code AI，可以直接把对应步骤提示词发给它。
- 如果 AI 不能访问本地文件，则需要你手动复制 `.tex` 文件内容给它，并使用本文档中的“单文件翻译提示词”。
- 每一步中的 `{...}` 是占位符，使用时替换成你自己的实际路径或文件名。

## 第 0 步：总控启动提示词

适用场景：第一次让 AI 接手整个 LaTeX 翻译任务时使用。

```text
你是一名精通英文 LaTeX 学术论文翻译、中文学术写作、LaTeX 编译与排版修复的双语专家。现在我需要你帮助我将一篇英文 LaTeX 论文翻译成中文，并生成可编译的中文 LaTeX 项目和 PDF。

英文 LaTeX 项目路径：
{英文论文 LaTeX 项目路径}

中文输出项目路径：
{中文译文输出路径}

主 LaTeX 文件名称：
{如果知道就填写，例如 Main.tex；如果不知道，请先自动识别}

任务目标：
1. 将英文 LaTeX 论文翻译为中文 LaTeX。
2. 保留原论文结构，包括标题、摘要、章节、小节、图表、算法、公式、引用、编号等。
3. 使用正式、通顺、忠实原文的中文学术论文表达。
4. 最终使用 XeLaTeX 或 latexmk 编译生成中文 PDF。
5. 不要直接修改英文原文目录，必须复制到中文输出目录后再修改。

最重要原则：
不要预设固定专业术语表。请先根据当前论文内容动态判断领域，并建立当前论文专属术语表。

术语优先级如下：
1. 用户明确提供的术语表、导师要求、学校要求。
2. 当前论文标题、摘要、关键词、引言、章节标题、图表标题中体现出的专属术语。
3. 当前论文所属学术领域中通行的中文译法。
4. 你已有知识中的候选译法。
5. 如果术语含义不确定，保留英文原词，并在首次出现时使用“中文译名（English term）”形式，必要时添加简短译注。

请先完成项目扫描、领域识别、工具链检查和动态术语表，然后向我汇报，不要马上开始全文翻译。
```

## 第 1 步：项目结构扫描提示词

适用场景：让 AI 先搞清楚 LaTeX 项目结构，避免直接乱翻译。

```text
请先扫描下面的英文 LaTeX 项目结构，不要修改任何文件。

英文 LaTeX 项目路径：
{英文论文 LaTeX 项目路径}

请完成以下工作：
1. 找到主 `.tex` 文件。
2. 找到所有章节 `.tex` 文件。
3. 找到图片资源目录和图片文件。
4. 找到参考文献文件，例如 `.bib` 文件或 `thebibliography` 所在的 `.tex` 文件。
5. 找到自定义 `.cls`、`.sty`、宏定义文件。
6. 分析主文件中的 `\input{}`、`\include{}`、`\includegraphics{}`、`\bibliography{}`、`\addbibresource{}`。
7. 判断项目更适合用 `xelatex`、`latexmk`、`bibtex` 还是 `biber` 编译。

请输出：
1. 主文件路径。
2. 章节文件列表。
3. 图片资源列表。
4. 参考文献处理方式。
5. 可能的编译命令。
6. 你发现的潜在 LaTeX 风险，例如文件名大小写、缺少图片、特殊宏包等。
```

## 第 2 步：论文领域识别提示词

适用场景：翻译前先判断论文属于哪个领域，以便动态确定术语。

```text
请根据当前 LaTeX 论文的标题、摘要、关键词、引言、章节标题和图表标题，判断这篇论文所属的学术领域。

请不要开始全文翻译。只做领域识别和依据说明。

请输出：
1. 论文标题。
2. 主要研究领域，给出 1 到 3 个候选领域。
3. 判断依据，例如标题关键词、摘要关键词、方法名称、实验对象、章节结构。
4. 论文类型，例如系统论文、实证研究、算法论文、理论论文、综述论文、实验评估论文、案例研究等。
5. 翻译风格建议，例如计算机安全论文风格、医学论文风格、工程控制论文风格、机器学习论文风格等。

注意：
同一个英文术语在不同领域可能有不同译法。请不要使用固定术语表，而是根据当前论文领域和上下文进行判断。
```

## 第 3 步：动态术语表生成提示词

适用场景：正式翻译前建立当前论文专属术语表。

```text
请基于当前论文内容生成一个动态术语表。该术语表只适用于当前论文，不要套用固定词典。

术语来源包括：
1. 论文标题。
2. 摘要。
3. 关键词。
4. 引言。
5. 章节标题。
6. 图表标题。
7. 方法名、模型名、系统名、算法名。
8. 数据集名、指标名、实验设置。
9. 反复出现的专业短语。
10. 容易混淆的近义术语。

术语优先级：
1. 用户明确提供的术语表、导师要求、学校要求。
2. 当前论文中作者自己的定义和用法。
3. 当前领域中文学术界常用译法。
4. 你的候选译法。
5. 不确定时保留英文原词，并在首次出现时写成“中文译名（English term）”。

请用下面格式输出：

| 英文术语 | 建议中文译法 | 首次出现格式 | 说明 |
|---|---|---|---|

请特别标注：
1. 必须保持英文不翻译的术语。
2. 可以翻译但首次出现应保留英文的术语。
3. 容易误译的术语。
4. 当前还不确定、需要后文确认的术语。

完成后，请等待我确认术语表，再开始大规模翻译。
```

## 第 4 步：复制项目并准备中文目录提示词

适用场景：让 AI 创建中文翻译项目目录。

```text
请将英文 LaTeX 项目完整复制到中文输出目录，作为中文翻译项目。

英文 LaTeX 项目路径：
{英文论文 LaTeX 项目路径}

中文输出项目路径：
{中文译文输出路径}

要求：
1. 不要直接修改英文原文目录。
2. 如果中文输出目录不存在，请创建。
3. 如果中文输出目录已经存在，请先检查其中内容，不要误删用户已有文件。
4. 复制时保留所有 `.tex`、`.bib`、`.cls`、`.sty`、图片、PDF、EPS、PNG、JPG 等资源。
5. 复制完成后，确认主文件、章节文件、图片资源和参考文献是否齐全。

完成后请输出：
1. 中文项目路径。
2. 主文件路径。
3. 复制的主要目录和文件。
4. 是否发现缺失资源。
```

## 第 5 步：中文 LaTeX 编译配置提示词

适用场景：修改主文件，让项目支持中文。

```text
请修改中文输出项目中的主 LaTeX 文件，使其支持中文 XeLaTeX 编译。

中文项目路径：
{中文译文输出路径}

主 LaTeX 文件：
{主 tex 文件路径}

要求：
1. 保留原始 documentclass 和整体结构。
2. 优先加入中文支持：

\usepackage[UTF8,fontset=windows]{ctex}

3. 如果当前环境不是 Windows，或字体报错，则改用：

\usepackage[UTF8,fontset=fandol]{ctex}

4. 不要删除原有宏包，除非它们与中文编译发生明确冲突。
5. 检查 `\input{}` 和 `\include{}` 文件名大小写是否与真实文件一致。
6. 检查 `\includegraphics{}` 图片路径是否仍然正确。
7. 如果原文标题是英文，请翻译 `\title{}`。
8. 作者姓名一般保留英文拼写。
9. 如果目标是毕业设计外文翻译材料，请翻译可见的作者单位、脚注、致谢等内容。

完成后，请说明你修改了哪些 LaTeX 设置，以及推荐使用的编译命令。
```

## 第 6 步：单章节翻译提示词

适用场景：逐个翻译 `.tex` 章节文件。

```text
请翻译下面这个 LaTeX 章节文件：

{中文项目中的章节 tex 文件路径}

请严格遵守：
1. 直接修改该文件。
2. 只翻译自然语言内容。
3. 保留所有 LaTeX 命令和结构。
4. 不要修改 `\cite{}`、`\label{}`、`\ref{}`、`\cref{}`、`\Cref{}` 中的内容。
5. 不要修改公式、变量名、函数名、类名、字段名、代码标识符、URL、图片路径、文件名。
6. 可以翻译章节标题、正文、图题、表题、表格可见文字、脚注和说明性文字。
7. 按当前论文动态术语表统一译法。
8. 对长句可以拆分为更自然的中文句子，但不能改变原文含义、逻辑关系或结论强度。
9. 保留所有数字、日期、百分比、金额、实验结果和编号。
10. 使用正式中文学术论文风格，避免口语化和机器翻译腔。

翻译完成后，请检查：
1. 是否漏译任何可见正文。
2. 是否破坏 LaTeX 命令。
3. 是否破坏公式、表格或代码。
4. 是否存在花括号不匹配。
5. 是否存在 `\begin{}` / `\end{}` 不匹配。

完成后请简要汇报：
1. 翻译了哪些内容。
2. 新增或调整了哪些术语。
3. 是否发现需要人工确认的术语或句子。
4. 是否建议立即编译检查。
```

## 第 7 步：长章节分段翻译提示词

适用场景：方法、实验、附录等很长的章节。

```text
请翻译下面这个较长的 LaTeX 文件：

{中文项目中的长章节 tex 文件路径}

这个文件较长，请不要一次性粗暴翻译。请按 section、subsection、subsubsection 或自然段分批处理。

要求：
1. 每次处理一小段后，检查 LaTeX 结构是否完整。
2. 保留所有公式、算法、代码、表格结构、引用、标签和路径。
3. 代码块、lstlisting、verbatim、minted 环境中的代码不要翻译。
4. algorithm 环境中的命令和变量不要翻译，但说明性文字、caption、comment 可以翻译。
5. 表格中的数字、符号、变量、模型名、数据集名不要改。
6. 表格中的自然语言表头和说明可以翻译。
7. 图题和表题可以翻译，`\label{}` 绝对不要翻译。
8. 如果发现新的关键术语，请更新当前论文动态术语表。

完成后请输出：
1. 已翻译的范围。
2. 新增或调整的术语。
3. 可能需要人工复核的地方。
4. 是否通过 LaTeX 结构检查。
```

适用场景：正文翻完后，专门检查 PDF 可见但容易漏翻的内容。

```text
请检查中文 LaTeX 项目中所有 PDF 可见文字，重点查找还没有翻译的英文内容。

中文项目路径：
{中文译文输出路径}

重点检查：
1. `\title{}`
2. 作者单位和 `\thanks{}`
3. 摘要
4. 章节标题
5. 图题 `\caption{}`
6. 表题 `\caption{}`
7. 表格表头和可见文字
8. algorithm caption
9. 脚注
10. 致谢
11. mdframed、quote、remark、note 等特殊环境中的可见文字
12. 附录标题和附录表格

请忽略：
1. 参考文献条目，除非我要求翻译。
2. LaTeX 注释。
3. 代码块。
4. 变量名、函数名、工具名、数据集名、模型名、URL、路径、哈希、地址。
5. 必须保留英文的缩写和专有名词。

如果发现应翻译但未翻译的内容，请直接修改中文项目中的对应 `.tex` 文件。

完成后请列出：
1. 修改了哪些文件。
2. 修复了哪些漏翻内容。
3. 哪些英文是刻意保留的。
```

## 第 9 步：术语一致性检查提示词

适用场景：全文翻译完成后统一术语。

```text
请对中文 LaTeX 项目进行术语一致性检查。

中文项目路径：
{中文译文输出路径}

当前论文动态术语表如下：

{粘贴当前论文术语表}

请检查所有 `.tex` 文件中的可见正文，确认：
1. 同一个英文术语是否始终使用同一个中文译法。
2. 不同英文术语是否被错误合并成同一个中文词。
3. 首次出现的重要术语是否采用“中文译名（English term）”形式。
4. 后续出现是否使用统一中文译名。
5. 领域术语是否符合当前论文语境。
6. 是否存在机器翻译腔或不符合中文学术表达的译法。

请不要修改：
1. 引用键。
2. label。
3. 公式。
4. 代码。
5. 图片路径。
6. 文件名。
7. URL。
8. 变量名和函数名。

请直接修正不一致译法，并在完成后输出：
1. 修改过的术语。
2. 修改原因。
3. 仍需人工确认的术语。
```

## 第 10 步：编译工具链检查提示词

适用场景：翻译完成或阶段性翻译完成后，准备编译 PDF。

```text
请检查当前机器是否具备编译中文 LaTeX PDF 所需工具。

请检查以下工具是否存在，并输出路径和版本：
1. xelatex
2. latexmk
3. bibtex
4. biber
5. kpsewhich
6. MiKTeX 或 TeX Live 相关工具

如果缺少必要工具，请根据当前操作系统给出安装方案。

如果当前是 Windows：
1. 优先检查是否有 winget。
2. 如果可以，请安装 MiKTeX 或 TeX Live。
3. 安装后刷新环境变量或使用工具绝对路径编译。

如果工具已存在，请推荐本项目的编译命令。

请不要开始编译，先输出工具链检查结果。
```

## 第 11 步：编译 PDF 提示词

适用场景：正式编译中文 PDF。

```text
请在中文 LaTeX 项目根目录编译 PDF。

中文项目路径：
{中文译文输出路径}

主 LaTeX 文件：
{主 tex 文件名，例如 Main.tex}

请优先使用：

latexmk -xelatex -interaction=nonstopmode {主 tex 文件名}

如果没有 latexmk，请使用：

xelatex -interaction=nonstopmode {主 tex 文件名}
xelatex -interaction=nonstopmode {主 tex 文件名}

如果项目使用 `.bib` 文件，请根据项目实际情况运行 BibTeX 或 biber，或直接使用 latexmk 自动处理。

如果参考文献是 `thebibliography` 环境，通常不需要 BibTeX。

编译完成后，请输出：
1. 是否成功生成 PDF。
2. PDF 路径。
3. 编译命令。
4. 是否还有未定义引用。
5. 是否还有未定义 citation。
6. 是否有致命 LaTeX 错误。
7. 剩余非致命 warning。
```

## 第 12 步：编译报错修复提示词

适用场景：LaTeX 编译失败。

```text
LaTeX 编译失败。请读取编译日志 `.log` 文件，定位第一个真正的错误并修复。

中文项目路径：
{中文译文输出路径}

主 LaTeX 文件：
{主 tex 文件名}

要求：
1. 不要只看日志最后一行，要找到第一个真正的 `! LaTeX Error`、`! Package Error`、`File not found`、`Runaway argument`、`Missing } inserted` 等错误。
2. 优先修复 LaTeX 语法、中文字体、宏包缺失、图片路径、文件名大小写、花括号不匹配、环境不匹配、表格列数不匹配等问题。
3. 不要为了通过编译而删除正文、图表、公式、算法、表格或参考文献。
4. 不要随意修改引用键、label、公式和代码。
5. 每次修复后重新编译，直到 PDF 成功生成。

请输出：
1. 第一个真实错误是什么。
2. 错误所在文件和行号。
3. 你如何修复。
4. 修复后是否编译成功。
5. 是否还有剩余 warning。
```


## 第 14 步：如果 AI 不能访问本地文件，使用这个单文件翻译提示词

适用场景：普通网页聊天 AI，不能读写你的本地文件。
