# 一分钟演示视频逐步脚本（精确操作版）

目标：录制一段 **55-60 秒** 的系统演示视频，用于 PPT 第 6 页。  
核心展示：**日志生成 → 上链存证 → 审计通过 → 篡改检测失败 → 自动告警**。  
录制原则：鼠标动作要慢半拍，页面结果出现后停 1 秒再切换；口播不要解释源码，不讲太细。

## 录制前准备（不要录进去）

1. 打开前端：`http://localhost:5173/dashboard`
2. 保持浏览器全屏，缩放建议 90% 或 100%。
3. 在“系统总览”页点击 **重置所有数据**。
4. 弹窗出现后点击 **确认重置**。
5. 等待页面指标刷新到 0 或接近空状态。
6. 鼠标放在页面中间，准备开始录屏。

> 注意：重置步骤不要录进去。正式视频从“系统总览”干净页面开始，逻辑最清楚。

## 正式录制总流程

需要点击的页面顺序：

`系统总览` → `日志生成器` → `日志中心` → `审计中心` → `异常告警`

需要点击的关键按钮：

`日志生成器` → `日报任务 / INFO` → `生成单条日志` → `去日志中心查看最新记录` → `审计中心` → `一键批量审计` → `篡改实验` → `异常告警`

## 逐秒操作与逐句台词

### 0-4 秒：系统总览开场

行为：

1. 录屏开始时停在 **系统总览** 页面。
2. 鼠标在页面中间轻轻移动一下，不要乱晃。
3. 画面展示左侧菜单和总览指标。

台词：

> 这里是系统总览页，可以看到系统围绕日志、链上存证、审计和告警做统一展示。

### 4-8 秒：进入日志生成器

行为：

1. 鼠标移动到左侧菜单。
2. 点击 **日志生成器**。
3. 页面切换后停 0.5 秒。

台词：

> 我先进入日志生成器，模拟产生一条任务日志。

### 8-13 秒：选择模板

行为：

1. 鼠标移动到页面上方的模板卡片区域。
2. 点击 **日报任务 / INFO** 模板。
3. 等表单自动填充后，鼠标可以轻轻划过“任务名称”“日志内容”等字段。

台词：

> 选择“日报任务 / INFO”模板后，系统会自动填充任务名称、来源路径、日志级别和日志内容。

### 13-20 秒：生成单条日志

行为：

1. 鼠标移动到表单底部。
2. 点击蓝色按钮 **生成单条日志**。
3. 等待右侧“提交结果”区域出现 **最近创建日志ID**。
4. 结果出现后停 1 秒。

台词：

> 点击生成后，后端会保存日志原文，计算 SHA-256 哈希，并调用 LogRegistry 合约完成链上存证。

如果生成按钮转圈时间稍长：

> 此时系统正在完成日志入库、哈希计算和链上写入。

### 20-26 秒：进入日志中心查看记录

行为：

1. 鼠标移动到右侧“提交结果”卡片底部。
2. 点击 **去日志中心查看最新记录**。
3. 日志中心页面出现后，把鼠标移到表格第一行。
4. 轻轻指向第一行的 **状态** 列，一般会显示“已上链”。

台词：

> 进入日志中心后，可以看到刚才生成的日志已经进入系统，状态显示为已上链。

### 26-31 秒：进入审计中心

行为：

1. 鼠标移动到左侧菜单。
2. 点击 **审计中心**。
3. 页面加载后，把鼠标移动到右上角按钮区域。

台词：

> 接下来进入审计中心，对日志进行完整性校验。

### 31-38 秒：执行一键批量审计

行为：

1. 点击右上角蓝色按钮 **一键批量审计**。
2. 等待按钮 loading 结束。
3. 指向页面上方的 **审计通过** 指标，或者指向表格中的“审计通过”状态。

台词：

> 点击一键批量审计后，系统会重新计算日志哈希，并与数据库记录和链上哈希进行三方比对；一致时审计通过。

如果审计按钮转圈时间稍长：

> 系统正在读取日志原文、重算哈希，并查询链上存证记录。

### 38-48 秒：执行篡改实验

行为：

1. 鼠标移动到审计中心右上角。
2. 点击 **篡改实验**。
3. 等待页面出现 **篡改实验结果** 卡片。
4. 鼠标指向步骤条里的 **审计检测** 或 **告警已生成**。
5. 如果右侧有“哈希不匹配”标签，鼠标可以指向这个标签。

台词：

> 现在点击篡改实验，模拟链下数据库中的日志内容被修改。系统重新计算后的哈希与链上存证不一致，所以审计结果变为失败。

### 48-55 秒：查看异常告警

行为：

1. 鼠标移动到左侧菜单。
2. 点击 **异常告警**。
3. 页面出现后，鼠标指向上方 **告警总数** 或 **待处理** 指标。
4. 再指向告警时间线或告警卡片中的 **高危** 标签。

台词：

> 切换到异常告警页，可以看到系统自动生成了高危的 hash_mismatch 告警。

### 55-60 秒：收尾

行为：

1. 停留在异常告警页。
2. 鼠标不要再切换页面，可以轻轻指向告警卡片。
3. 讲完后停止录制。

台词：

> 这说明系统跑通了日志生成、链上存证、审计比对、篡改检测和异常告警的完整闭环。

## 连贯版完整口播稿

如果你不想看表格，可以直接照这一段说：

> 这里是系统总览页，可以看到系统围绕日志、链上存证、审计和告警做统一展示。  
> 我先进入日志生成器，模拟产生一条任务日志。选择“日报任务 / INFO”模板后，系统会自动填充任务名称、来源路径、日志级别和日志内容。  
> 点击生成后，后端会保存日志原文，计算 SHA-256 哈希，并调用 LogRegistry 合约完成链上存证。  
> 进入日志中心后，可以看到刚才生成的日志已经进入系统，状态显示为已上链。  
> 接下来进入审计中心，对日志进行完整性校验。点击一键批量审计后，系统会重新计算日志哈希，并与数据库记录和链上哈希进行三方比对；一致时审计通过。  
> 现在点击篡改实验，模拟链下数据库中的日志内容被修改。系统重新计算后的哈希与链上存证不一致，所以审计结果变为失败。  
> 切换到异常告警页，可以看到系统自动生成了高危的 hash_mismatch 告警。  
> 这说明系统跑通了日志生成、链上存证、审计比对、篡改检测和异常告警的完整闭环。

## 如果录制超过 60 秒，删哪里

优先删除这两处停留：

1. **日志中心** 只停 2 秒，不需要读表格每一列。
2. **审计中心审计通过** 只展示指标或表格状态，不解释三方哈希细节。

不要删除：

1. **篡改实验**
2. **异常告警**

因为这两个画面最能说明你的系统核心价值。

## 如果你想更稳，推荐这个最短版本（45-50 秒）

行为：

1. 系统总览页开场。
2. 点击 **审计中心**。
3. 点击 **篡改实验**。
4. 等待出现 **篡改实验结果**。
5. 点击 **异常告警**。
6. 指向高危告警。

台词：

> 这里是系统总览页。为了展示系统核心能力，我进入审计中心执行篡改实验。  
> 篡改实验会自动创建一条日志并上链存证，然后模拟修改链下数据库中的日志内容。  
> 审计时，系统重新计算当前日志哈希，并与链上存证进行比对。由于哈希不一致，审计结果被判定为失败。  
> 切换到异常告警页，可以看到系统自动生成了高危的 hash_mismatch 告警。  
> 这说明系统能够识别日志篡改，并完成从审计检测到告警展示的闭环。
