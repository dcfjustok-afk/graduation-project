# 参考文献整理提示

本文件仅用于后续整理真实参考文献，不作为论文正文内容。参考文献最终必须从学校图书馆数据库、知网、万方、维普、IEEE Xplore、ACM Digital Library、SpringerLink、ScienceDirect、Google Scholar、官方技术文档等可靠来源检索，并按 GB/T 7714-2015 格式人工核对作者、题名、来源、年份、卷期、页码、DOI 或 URL 等信息。不得编造作者、年份、期刊名称或文献编号。

## 七、整理注意事项

1. 优先选择近五年高质量论文、权威标准、官方文档和经典基础文献。
2. 区块链基础、哈希算法标准等基础内容可适当引用经典文献或标准文档。
3. 系统开发技术可引用官方文档，但需按学校要求判断是否适合作为参考文献。
4. 研究现状部分引用应与正文观点对应，避免堆砌无关文献。
5. 中文文献与英文文献应保持适当比例，具体数量以学院论文要求为准。
6. 最终参考文献必须按 GB/T 7714-2015 格式人工核对，不得直接使用未经核验的自动生成条目。
