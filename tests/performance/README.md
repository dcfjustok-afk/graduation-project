# performance

这个目录用于存放性能测试脚本与结果。

## 需要完成的内容
- 编写日志批量提交压测脚本
- 编写批量审计压测脚本
- 统计吞吐量、成功率、响应时间
- 输出实验数据表格或图表

## 核心目标
- 量化系统在不同负载下的表现
- 为论文中的性能分析章节提供数据支持

## 当前已补充的性能脚本

- `node tests/performance/log-submit-benchmark.js`：批量提交日志并统计吞吐量、成功率、延迟
- `node tests/performance/audit-benchmark.js`：重复执行批量审计并统计平均处理时延

脚本默认将结果输出到 `tests/performance/results/` 目录，便于后续整理进论文实验章节。
